# 通讯录管理系统

一个基于C++开发的控制台通讯录管理系统，支持联系人的增删改查等基本功能。

## ✨ 功能特性

- ✅ 添加联系人信息
- ✅ 显示所有联系人
- ✅ 删除指定联系人
- ✅ 查找联系人
- ✅ 修改联系人信息
- ✅ 清空通讯录
- ✅ 输入验证和错误处理

## 🛠️ 技术栈

- **语言**: C++
- **开发环境**: Visual Studio
- **版本控制**: Git + GitHub
